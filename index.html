设计规则

  • 所有组件(振荡器、滤波器、键盘、喇叭……)本体上没有任何开关、旋钮或按钮。
  • 想调参数?「旋钮」「开关」本身也是组件,它们的输出接到目标组件的 3.5mm IO 口上。
  • 画布是纯网格制:组件尺寸、接口位置全部以「格」为单位(格距可在工具栏调整:16 / 20 / 24 / 32px),严格对齐网格。
  • 一根线缆 = 一条 3.5mm 线;所有信号(CV / Gate / 音频)走同样的线。
  • 参考 Reaktor Blocks / VCV Rack 的惯例,接口与线缆按信号类型着色:● 红 = 音频、● 蓝 = CV 电压、● 绿 = 门 / 时钟、● 灰 = 任意信号、● 紫 = MIDI(3.5mm TRS-MIDI 惯例)。
  • 组合与嵌套:Shift+点选多个组件 → 工具栏「封装」,边界线缆自动改为组合面板上的新 3.5mm 口;组合可再参与封装(无限嵌套),右键组合 = 解体还原。
  • 组件工坊:点工具栏「工坊」,用「＋旋钮 / ＋推子 / ＋开关 / ＋电压表」拼出你自己的面板,改名字、定量程、换配色,「放置组件」后它就是画布上一个真正的组件——每个旋钮 / 推子 / 开关是一路 3.5mm 输出口,电压表是一路输入口。设计会存进左侧「我的组件」随时复用;右键画布上的自制组件 = 载回工坊继续修改。
  • 只有最终能把信号送到喇叭(或示波器 / XY 示波器 / 录音机)的组件才会被模拟,其余组件自动休眠变暗;连通性按组件内部信号路径计算(例如滤波器 IN 没接线时,喂 CUTOFF 的旋钮链也算休眠)。
  • MIDI 键盘 / MIDI 音序器是 MIDI 设备:MIDI 口发音符信号,并内置 MIDI→CV 转换直接输出 CV;也可以把 MIDI 口接到独立的「MIDI-CV」模块再转。

快速上手(减法合成)

  1. 点「演示音色」载入示例:键盘 → 振荡器 → 滤波器 → 压控放大 → 喇叭,包络 ADSR 控制音量,旋钮控制滤波。
  2. 点亮「电源」,按电脑键盘 A W S E D F T G Y H U J K…(或点击琴键)演奏。Z / X 切换键盘八度。
  3. 想加颤音:放一个 LFO,把它任一波形输出接到振荡器的 FM 口。
  4. 想用音序器:给「音序器」的 CLK 接时钟(LFO 方波输出),V1~V8 各接一个旋钮设定每步电压,CV → 量化器 → 振荡器音高。
  5. 录音机:信号接 IN,「开关」输出接 REC 开始录音、接 PLAY 播放、LOOP 接高电平循环。
  6. 想要一套顺手的专属控制面板?打开「工坊」拼一个自制组件:旋钮 / 推子 / 开关各就各位,放置后接线即用,设计存入「我的组件」可反复放置。

电压约定

  • 旋钮输出 0 ~ +10V;音高 1V/oct(振荡器 0V = C4);LFO ±1V;Gate 高电平 = 10V。
  • 未接线的输入口使用默认值(如滤波共振默认少量、VCA 未接控制时全开)。

快捷操作

  • 从接口拖出 = 接线;从已接线的接口拖出 = 把那根线拔下来换地方;双击接口 = 拔掉它的所有线;单击线缆 = 删除。
  • 拖动组件头部移动(自动吸附网格);拖空白处平移;滚轮缩放;Del 删除选中组件;Ctrl+D 复制。
  • 支持 Web MIDI:插入 MIDI 键盘后,「键盘」组件自动接收(浏览器询问权限时允许即可)。

Design rules

  • No module (oscillator, filter, keyboard, speaker…) has any switch, knob or button on its body.
  • Want to tweak a parameter? Knobs and switches are modules too — patch their output into the target module's 3.5mm jacks.
  • The canvas is strictly grid-based: module sizes and jack positions are measured in grid cells (grid density is adjustable in the menu bar: 16 / 20 / 24 / 32px).
  • One cable = one 3.5mm wire; all signals (CV / Gate / audio) run down the same kind of wire.
  • Following the Reaktor Blocks / VCV Rack convention, jacks and cables are colored by signal type: ● red = audio, ● blue = CV, ● green = gate / clock, ● gray = any signal, ● purple = MIDI (3.5mm TRS-MIDI convention).
  • Composites and nesting: Shift+click several modules → “Encapsulate”; boundary cables automatically become new 3.5mm jacks on the composite panel. Composites can be encapsulated again (unlimited nesting); right-click a composite to dissolve it.
  • Component workshop: open “Workshop” from the menu bar and build your own panel with “+ Knob / + Fader / + Switch / + Meter” — rename them, set ranges, pick colors, then “Place” and it becomes a real module on the canvas: each knob / fader / switch is one 3.5mm output, the meter is one input. Designs are saved under “MINE” for reuse; right-click a custom module on the canvas to load it back into the workshop.
  • Only modules that can ultimately feed a speaker (or scope / XY scope / recorder) are simulated; everything else automatically sleeps and dims. Connectivity follows the internal signal path (e.g. a knob chain feeding CUTOFF counts as asleep while the filter's IN is unpatched).
  • MIDI keyboard / MIDI sequencer are MIDI devices: the MIDI port emits notes and has a built-in MIDI→CV conversion that outputs CV directly; you can also patch MIDI into the standalone “MIDI-CV” module.

Quick start (subtractive synthesis)

  1. Load “Demo patch” from the Songs menu: keyboard → oscillator → filter → VCA → speaker, with an ADSR controlling volume and knobs controlling the filter.
  2. Switch the power on and play with your computer keyboard A W S E D F T G Y H U J K… (or click the piano keys). Z / X shift the keyboard octave.
  3. Vibrato: place an LFO and patch any of its waveform outputs into the oscillator's FM jack.
  4. Sequencing: clock the sequencer's CLK from an LFO square output, give V1~V8 a knob each to set the step voltages, then CV → quantizer → oscillator pitch.
  5. Recorder: signal into IN, a “switch” into REC to record, PLAY to play back, LOOP high to loop.
  6. Want a personal control surface? Open the “Workshop” and assemble a custom module — knobs / faders / switches in place, place it and patch away; designs live under “MINE” for repeated use.

Voltage conventions

  • Knobs output 0 ~ +10V; pitch is 1V/oct (oscillator 0V = C4); LFO ±1V; gate high = 10V.
  • Unwired inputs use defaults (a little filter resonance, VCA fully open with no control, etc.).

Shortcuts

  • Drag from a jack = patch; drag from an already-patched jack = unplug that cable and move it; double-click a jack = unplug everything from it; click a cable = delete it.
  • Drag a module header to move it (snaps to the grid); drag empty space to pan; wheel to zoom; Del deletes the selection; Ctrl+D duplicates.
  • Web MIDI supported: plug in a MIDI keyboard and the “MIDI keyboard” module receives it automatically (allow the browser permission prompt).
